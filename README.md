# YIGH - Youth Initiative for Green Hydrogen

Africa's largest youth network in green hydrogen.

## Features
- Responsive modern design
- Membership signup with Google Apps Script
- Opportunities & careers page
- Events section
- Team showcase
- Partners section

## Tech Stack
- HTML5
- Tailwind CSS
- JavaScript
- Google Apps Script (backend)
- Lucide Icons

## Setup
1. Clone the repository
2. Open index.html in your browser
3. Deploy Google Apps Script for form submissions
